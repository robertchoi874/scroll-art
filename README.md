The first image is a snowglobe and the second is a Rubick's cube. Both are 1 citation point since I made them by myself. I was inspired by the miniature snowglobe on the ASCII website you showed us. I did a Rubick's cube for the second one because I use to do them and I thought it might look cool (which it did). It was difficult to get a circle and make it look right. The Rubick's cube was a lot more satisfying to make and was probably my favorite part about it since the slashes and dashes just lined up so perfectly. Conversely, making the outline for the snowglobe was my lest favorite part, but doign the interrior was ok. I did all of my work in a google doc becuase I though that would be easiest. Then, I realized that in terminal everything is spaced out evenly so I had to use the consolas font and basically redo my work, which is what took me a while to complete this project (I can't make circles). 
All of the images are within the limits. The snowglobe is a 40x28 (length, height)and the rubicks cube is a 52x25
Instead of using the intended solution [0][0] = " ", etc. I decided to (since I already had my images in a google doc) to make each row a string and then turn each row into a char array. Part of the reason I did this might have been because that solution was intended for small ASCII drawings, and I did not want to write 2000+ lines of declaring each individual char. I made 2 functions for drawing each image and a 3rd to turn the strings into char arrays. Each image is a 2d char array, so it is basically an array of arrays which is why this solution is available (instead of imagining it as a grid). This 3rd function is basically the same thing as the .toCharArray but I needed to fill the requirement for 3 functions and I only discovered the existence of this function while trying to code this function since it popped up as a suggestion for the return line. The point of this project was to learn something about 2d char arrays and coding the toCharArray function myself, although maybe being redundant, was a good way to actually learn something about char arrays and how they work (an array of arrays, and how you can turn strings to chars which I did not knwo before). 
By doing this solution I did in fact learn something new about char matrixes when I am already strong in java (not much review or difficulty coding) and know about most of these concepts. I think that the code for this project was more on the simple side since we basically went over all of the answers in class and I was confused why the example on github had so many functions and I spent time trying to understand what was happening there just to realize that the solution was not that complicated. I am not sure how this code could be improved, but there is probably something that was done in the example that made the code better, perhaps getting the "unix terminal width."
I think it is actualyl quite possible for both to be accepted into the collection because they are easily distinguishable and look decently good.
